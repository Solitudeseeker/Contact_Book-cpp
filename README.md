==== Contact Book ====

It is a project made with C++ that is designed to use as a Contact Book.

>>Features We Have:

- Add contacts
- Display contacts
- Search contacts
- Edit contacts
- Delete contacts
- Prevent duplicate phone numbers
- Save contacts to a file
- Load contacts when the program starts

>>Technologies Used:

- C++
- STL Vector
- File Handling
- Git & GitHub

>>How to Run:

For Compilation-

g++ main.cpp -o a

To Run-

./a
